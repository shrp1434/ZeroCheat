# Asset Register

The master list of art assets for *Fight Animals for Eggs*: animals (ANM), eggs (EGG), bosses (BOS), base modules (MOD), environment kits (ENV), UI kits (UI) and variant material sets (VAR). ID prefixes are defined in `CLAUDE.md` §9. Animation (ANI), visual effect (VFX), sound (SFX) and music (MUS) catalogues are owned by [[Animation Bible]], [[VFX Bible]], [[Sound Bible]] and [[Music Direction]]; this register points to them and does not duplicate their IDs.

> [!info] PROPOSED
> Every specification in this register (sizes, budgets, materials, priorities) is a production proposal derived from the art direction pages. The content behind some rows is **CONFIRMED** (for example the Egg Merging Station, D-020, and the 60-animal target, D-004), but the roster itself (D-032), module availability ([[Open Questions#Q-007]]) and variant acquisition ([[Open Questions#Q-006]]) are not final.

## How to read this register

| Column | Meaning |
|---|---|
| Asset ID | Permanent ID; never reused, even if an asset is cut ([[Asset Naming Conventions]]) |
| Dimensions or proportions | Longest axis in studs unless stated; size classes from [[Animal Modelling Principles]] |
| Model structure | Body plan code (animals) or main part structure |
| Textures | "Shared atlas 256" = shared 256×256 palette atlas; "SA" = SurfaceAppearance with C(olour), N(ormal), R(oughness), M(etalness) maps ([[Material and Texture Direction]]) |
| Colour values | Key colours; species palettes live in each animal document |
| Lighting | Presets the asset must be approved under ([[Lighting Direction]]) |
| Animation / VFX / Sound | Pointer to the owning catalogue |
| Performance budget | Triangle budget at LOD0 (plus part or particle caps where relevant) |
| Production priority | Vault scale: **P0** essential for launch, **P1** launch-desirable, **P2** can follow shortly after launch, **P3** later. "Wave" orders production inside P0: wave 1 = vertical slice (Hub and Whisperwood Forest), wave 2 = regions 2–5, wave 3 = regions 6–8 |

Body plan codes: QDR quadruped, HOP hopper, UPR upright small mammal, PRM primate, BGD ground bird, BFL flyer, SRP serpentine, SPR sprawling reptile, THR theropod, PIN pinniped, SWM air-swimmer, CEP cephalopod, ART arthropod. Definitions in [[Animal Modelling Principles]]; rigs in [[Animal Rig Standards]].

## 8. Maintenance rules

1. Add a row before production starts on any new asset; IDs are allocated sequentially within each prefix and never reused.
2. When an animal is added or cut from the roster (D-032 is **PROPOSED**), the ANM numbering follows the catalogue order in [[Canonical Proposed Values]] §2; a renumbering requires a [[Changelog]] entry and a search for references.
3. Budgets here must match [[Animal Modelling Principles]], [[Base Art Direction]], [[Boss Art Direction]] and [[Environment Art Direction]]. Those pages win on conflict.
4. Production status (concept, blockout, final, approved) is tracked in the production backlog ([[Product Backlog]]), not in this register.
