# Visual Reference Placeholders

There is **no concept art yet**. This page holds clearly labelled placeholders that describe exactly which concept images are needed and the brief for each. When an image is produced, it is stored under `Art/Reference/` ([[Asset Naming Conventions]]) and embedded here in place of the placeholder text.

> [!danger] Image rules
> - No stock imagery, no images found online, no AI-generated images presented as studio work, no fan art of other games. Every reference must be original work produced for this project, in-house or under contract.
> - No fake image links. A placeholder stays a placeholder until a real file exists in the vault.
> - Every concept must respect the **CONFIRMED** visual direction (D-026): colourful, polished, low-poly, clear silhouettes, no horror, no brainrot, no meme animals.

The only images currently in the vault are two original diagrams made from the PROPOSED specifications (they are diagrams, not concept art):

## How placeholders work

| Field | Meaning |
|---|---|
| REF ID | Local placeholder number on this page (REF-01, REF-02, ...). Not an asset ID |
| Asset IDs | Register rows the image serves ([[Asset Register]]) |
| Deliverable | Image type, views and size |
| Brief | What the image must communicate |
| Must show / Must avoid | Acceptance criteria |
| Status | Not started → In progress → Review → Approved |

Default deliverable sizes: turnarounds 3,840 × 2,160 px; key art 3,840 × 2,160 px; sheets 2,560 × 1,440 px. Files are PNG.

> **Asset IDs:** ENV-002, ANM-001, ANM-013, ANM-024 · **Deliverable:** one painted key frame, 16:9 · **Status:** Not started
> **Brief:** The look of the game in one image. A player avatar mid-dodge with three companions (Rabbit, Fox, Wolf) fighting a wild Boar in a sunny Whisperwood Forest clearing. Warm afternoon light per [[Lighting Direction]], hero oak landmark in the background, Uncommon and Common nameplates visible.
> **Must show:** low-poly facets on every animal; readable silhouettes; telegraph decal under the Boar in `#FF4B3E`; damage numbers in feedback colours from [[Colour Palette]].
> **Must avoid:** blood, teeth at rest, dark shadows, photographic textures.

> [!example] VISUAL REFERENCE PLACEHOLDER — REF-02 Tone do and don't board
> **Asset IDs:** none (guidance) · **Deliverable:** 2,560 × 1,440 comparison sheet · **Status:** Not started

> [!example] VISUAL REFERENCE PLACEHOLDER — REF-15 ANM-034 Tiger turnaround
