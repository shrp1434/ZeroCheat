# Module - Shield Generator

**Asset ID:** MOD-04 (**PROPOSED**). **Slot:** flexible, recommended mid-plot so its dome visibly covers the base.

> [!success] CONFIRMED
> Bases are protected by **shields** and physical defences (D-024). Offline bases cannot be raided, so shields only ever matter while the owner is online.

> [!warning] UNDECIDED
> - How shields are acquired (automatic after a raid, generated by the base, or purchasable): **UNDECIDED** ([[Open Questions#Q-030]]). Shield rules are owned by [[Shield Mechanics]].
> - Raid duration: **UNDECIDED** ([[Open Questions#Q-012]]).
> - Module availability: **UNDECIDED** ([[Open Questions#Q-007]]).

## 1. Purpose

Gives the owner a period during which no raid can start on their base. The generator's job depends on how Q-030 is resolved:

| Q-030 option | Generator role |
|---|---|
| Generated by the base | The generator **produces and stores** shield time, and the owner activates it |
| Automatic after a raid | The generator **extends** the automatic post-raid shield and shortens its cooldown |
| Purchasable | The generator holds purchased shields. **Not recommended**: selling protection from other players is pay-to-win and is excluded by [[Monetisation Principles]] |

> [!info] PROPOSED recommendation
> Model the generator for the "generated by the base" option, combined with a short automatic post-raid grace shield owned by [[Shield Mechanics]]. Shields are never sold for Robux. Final decision: **UNDECIDED** ([[Open Questions#Q-030]]).

## 2. Footprint and appearance

| Property | Proposal |
|---|---|
| Footprint | 16 × 16 studs, 12 tall (L5: 20) |
| Appearance | A pylon of stacked egg-shaped crystals inside a ring of standing stones. When active, a translucent honeycomb dome covers the whole plot |
| Materials | Stone, brass coils, crystal; dome is a ForceField-style material in the owner's chosen cosmetic tint |

## 3. Upgrade levels (modelled for the "generated by the base" option)

All shield values are **PROPOSED** and configurable, and should be re-checked against the chosen `T_raid`.

| Level | Cost (Cash) | Max stored shield | Charge rate (while owner online) | Activation cooldown after a shield ends | Visual change |
|---:|---:|---:|---:|---:|---|
| L1 | 2,500 | 20 min | 10 min per hour | 10 min | Single crystal on a timber stand, faint dome |
| L2 | 6,250 | 30 min | 12 min per hour | 9 min | Stone ring, two crystals, brass coil |
| L3 | 15,625 | 45 min | 15 min per hour | 8 min | Three crystals, rotating brass rings |
| L4 | 39,063 | 60 min | 18 min per hour | 7 min | Violet crystal cluster, dome gains hex shimmer |
| L5 | 97,656 | 90 min | 20 min per hour | 6 min | Golden crown, prismatic dome with drifting motes |

Total: **161,094 Cash**.

Design check: at L5 an owner who plays for two hours accumulates up to 40 minutes of shield, so they are shielded for about a third of their session. The rest of the time the base is raid-eligible (if they opted in, Q-011). That keeps raiding alive while giving defenders control over when they are exposed (for example, before a long hatching session at the base).

## 4. Functionality

| Function | Proposal |
|---|---|
| Activate | ProximityPrompt at the pylon or a button in [[UI - Base Management]]; uses all or part of the stored shield in 5-minute steps |
| Cannot activate | During an active raid on this base, or during the activation cooldown |
| Shield active | Raid requests against this base are rejected with `ShieldActive`. The Raid Board shows a dome icon |
| Shield and the owner's own raiding | Whether attacking another base breaks the attacker's shield is owned by [[Shield Mechanics]] (recommended: yes, to prevent "shielded raider" abuse) |
| Offline | No charge, no drain; bases are not raidable offline anyway |
| Progression Score | Levels count towards the 44 base levels |

## 5. Dependencies

- Free slot; level cap `PlotStage + 1`.
- Depends on Q-030; if Q-030 resolves to "automatic after a raid only", the level table is remapped to post-raid shield extension (+0/+2/+4/+6/+8 minutes, **PROPOSED**).

## 6. Technical implementation

| Layer | Detail |
|---|---|
| Server data | `base.modules.ShieldGenerator = { level, slot }`, `base.shield = { storedSeconds, activeUntil, cooldownUntil }` stored as server timestamps (`os.time()`) |
| Charging | Accrued in [[Service - BaseService]] on a 60 s server tick while the owner is in the server; capped at max stored |
| Instances | `Plot_##.Modules.ShieldGenerator`, `Plot_##.ShieldDome` (a single non-collidable mesh, transparency tweened) |
| Replication | Attributes `ShieldActiveUntil`, `ShieldStored` on the plot; the client shows timers |
| Raid check | [[Service - RaidService]] reads `activeUntil` before creating a session; the check and session creation are atomic on the server |
| Streaming | The dome is part of the plot model so it is visible from the hub bridge |

```lua
-- Illustrative Luau (not executed)
local function isShieldActive(base): boolean
	return base.shield.activeUntil ~= nil and os.time() < base.shield.activeUntil
end

local function activateShield(base, seconds: number): (boolean, string?)
	if RaidService.IsBaseUnderRaid(base.ownerUserId) then return false, "RaidActive" end
	if base.shield.cooldownUntil and os.time() < base.shield.cooldownUntil then return false, "Cooldown" end
	seconds = math.min(seconds, base.shield.storedSeconds)
	if seconds < 300 then return false, "TooShort" end
	base.shield.storedSeconds -= seconds
	base.shield.activeUntil = os.time() + seconds
	return true
end
```

## 7. Animation and VFX

- Activation: crystals spin up, a pulse rises from the pylon and the dome unfolds from the top in 1.5 s ([[Animation - Shield Activation]]).
- Active: slow hex shimmer, soft hum ([[Sound - Base and Raid Alerts]]).
- Expiry warning: dome flickers for the last 30 s.
- Deactivation: dome shatters into harmless sparkles.
- Cosmetic tints available as base cosmetics ([[Monetisation Product Concepts]]); tints never change transparency, so a raider can always see whether a dome is up.

## 8. Raid interaction

| Situation | Behaviour |
|---|---|
| Shield up | No raid can start |
| Raid in progress | Shield cannot be activated; the generator is not a target |
| After raid | Automatic grace shield per [[Shield Mechanics]] (duration **UNDECIDED**) |
| Disabling | Not possible (**PROPOSED**; see Q-403) |
