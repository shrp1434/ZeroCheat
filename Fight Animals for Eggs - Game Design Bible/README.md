# Fight Animals for Eggs — Game Design Bible

The complete documentation vault for **Fight Animals for Eggs**, a Roblox animal-collection, real-time combat, egg-hatching and base-building game.

## Open it

1. Install [Obsidian](https://obsidian.md).
2. **Open folder as vault**, then select this folder.
3. Start at `00 - HOME AND NAVIGATION/Home.md`.

No community plugins are required. Mermaid diagrams, callouts and wikilinks all render with Obsidian's core features.

## What's inside

| Folder | Contents |
|---|---|
| 00 | Home, dashboards, vault map, how to use the vault |
| 01–03 | Vision, core gameplay, world design (regions and bosses) |
| 04 | 60 animal documents and the animal data model |
| 05–10 | Combat, eggs and hatching, ascension and progression, bases, PvP and raiding, economy and monetisation |
| 11–14 | UI/UX, art direction, animation and VFX, sound |
| 15–18 | Technical architecture, Luau implementation, multiplayer and security, data and balancing |
| 19–21 | QA, roadmap, live operations |
| 22–27 | References, decisions, backlog, templates, glossary, assets |

## Ground rules

- Every mechanic is marked **CONFIRMED** (owner decision), **PROPOSED**, **UNDECIDED** or **DEPRECATED**.
- All proposed numbers live in `18 - DATA AND BALANCING/Canonical Proposed Values.md`.
- Luau code in this vault is illustrative and has not been executed in Roblox Studio.
- Contribution rules: `CLAUDE.md`.
