# Game Vision Index

The vision folder states **why** *Fight Animals for Eggs* exists, **who** it is for, **what makes it different** and **which promises it keeps**. Every other folder should be traceable back to a pillar or principle here. Start with the vision statement, then read the fairness charter before designing anything that touches luck, spending or loss.
