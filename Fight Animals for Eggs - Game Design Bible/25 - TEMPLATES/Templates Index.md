# Templates Index

Templates for every recurring document type. The vault's `.obsidian/templates.json` points the core **Templates** plugin at this folder, so templates can be inserted with the command palette ("Templates: Insert template"). `{{title}}` and `{{date}}` placeholders fill in automatically.

> [!tip] Before you create a document
> 1. Check the [[Vault Map]]: the document may already exist.
> 2. Pick the matching template below.
> 3. Use numbers from [[Canonical Proposed Values]] only.
> 4. Add the new document to the [[Vault Map]] and its folder index.

| Template | Use for | Owner discipline |
|---|---|---|
| [[Template - Animal]] | A new species | Animal and Character Designer |
| [[Template - Game System]] | A system spanning several features | Senior Game Designer |
| [[Template - Feature]] | A single shippable feature | Game Designer |
| [[Template - World Region]] | A new region | World Designer |
| [[Template - Boss]] | Mini-bosses and world bosses | Combat Designer |
| [[Template - Egg]] | A new egg type | Systems Designer |
| [[Template - UI Screen]] | A screen or panel | UI/UX Designer |
| [[Template - Animation]] | An animation clip or set | Animation Director |
| [[Template - VFX]] | A visual effect | VFX Artist |
| [[Template - Sound]] | A sound effect or set | Sound Designer |
| [[Template - Technical Service]] | A server or client service | Technical Architect |
| [[Template - Data Schema]] | A persisted data structure | Data Architect |
| [[Template - Test Case]] | A test suite | QA Director |
| [[Template - Task]] | A backlog item | Production Manager |
| [[Template - Decision]] | A decision record | Executive Game Director |
| [[Template - Update]] | A live update or patch | Live Operations Director |

Frontmatter fields for each type are defined in [[Frontmatter Schemas]].
