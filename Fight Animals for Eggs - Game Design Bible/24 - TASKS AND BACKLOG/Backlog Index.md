# Backlog Index

This folder holds the production backlog for *Fight Animals for Eggs* and the quality bar every item must meet. The backlog is ordered by priority and dependency, not by dates: the vault deliberately contains no deadlines.

## Orientation

- **What to build next?** Open the [[Product Backlog]]. Pick the highest-priority story whose dependencies are done and whose Definition of Ready is met.
- **Is it finished?** Check the story's acceptance criteria and the checklist for its work type in the [[Definition of Done]].
- **Blocked by an open question?** The story's *Depends on* column lists the Q-ID; the Production Manager raises it with the owner via [[Open Questions]].
- **Where do milestones come from?** [[Development Roadmap]] and the milestone pages (from [[M01 - Pre-production]] to [[M23 - Live Updates]]).
- **Adding work?** Use [[Template - Task]] and place the story in the right epic.

| Priority | Backlog meaning | Test and bug meaning |

| P0 | Essential | Must pass / fix immediately |
| P1 | High | Core behaviour / fix this milestone |
| P2 | Medium | Secondary / fix when capacity allows |
| P3 | Low | Nice to have / fix if convenient |
