# References Index

External reference material and tooling guidance for the team. This folder points outwards: to official Roblox documentation topics, to genre conventions described in general terms, and to Obsidian setup. It never contains copied content from other games or unverified external research.

## Documents

| Document | One-line description |
|---|---|
| [[Roblox Platform References]] | Official Roblox documentation topics (data stores, memory stores, messaging, PolicyService, MarketplaceService, paid random items policy, Community Standards, streaming, animation, performance), with checked links or "URL to be verified" |
| [[Design Inspiration Notes]] | Collection simulator, monster-taming, base-raiding and co-op boss conventions, with what the game adopts and avoids to keep its own identity |
| [[Recommended Obsidian Plugins]] | Core plugins to enable (Templates with folder `25 - TEMPLATES`, Graph view, Backlinks, Outline) and optional community plugins; the vault works without them |

## How to use these references

- Engineers: read the relevant entry in [[Roblox Platform References]] before implementing a service, and record any API fact the vault relies on in [[Roblox API Reference Notes]].
- Designers and artists: check new content against the identity checklist in [[Design Inspiration Notes]].
- Everyone: set up Obsidian once using [[Recommended Obsidian Plugins]].
